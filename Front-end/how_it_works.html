End-To-End Architecture

How SignDetect AI Works

A seamless machine learning pipeline translating raw optical camera pixels into real-time classified sign language speech in milliseconds.

1

Frame Capture

OpenCV accesses live webcam frames (640x480) at 30 FPS, continuously converting raw BGR arrays to RGB color space for ML tensor processing.

2

Landmark Extraction

Google MediaPipe Hands isolates the hand region and extracts 21 3D spatial keypoints (wrist, knuckles, fingertips) with sub-pixel precision.

3

Feature Normalization

Keypoints are translated relative to the hand's minimum origin $(x - \min(X), y - \min(Y))$, constructing a 42-dimensional scale-invariant vector.

4

Random Forest Inference

An ensemble of decision trees classifies the 42 features against trained patterns in <1ms, predicting the sign label and vocalizing via TTS.

Biometric Mapping

MediaPipe 21 Hand Landmarks

MediaPipe uses a machine learning pipeline consisting of a palm detector model that operates over the full image and a hand landmark model that predicts 21 3D landmarks inside the detected hand region.

0: WRIST

Root anchor keypoint

1-4: THUMB

CMC, MCP, IP, TIP

5-8: INDEX FINGER

MCP, PIP, DIP, TIP

9-12: MIDDLE FINGER

MCP, PIP, DIP, TIP

13-16: RING FINGER

MCP, PIP, DIP, TIP

17-20: PINKY

MCP, PIP, DIP, TIP

🖐️

42 Normalized Features

Each hand contains 21 landmarks. With 2 coordinates $(x, y)$ per landmark normalized relative to bounding origin, the model receives a compact 42-dimensional vector.

Vector = [x₀-min(x), y₀-min(y), x₁-min(x), y₁-min(y), ..., x₂₀-min(x), y₂₀-min(y)]
